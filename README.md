# WhatsApp Clone

A mobile-first WhatsApp-inspired chat application built as an independent project.

## Planned features

- Real-time 1-to-1 messaging
- Group chats
- Online/offline presence
- Typing indicators
- Read receipts
- Image and file sharing
- Status/stories
- Chat search
- Profile and settings
- Responsive desktop and mobile UI
- Supabase Auth, Realtime, Database and Storage
- Android APK build with Capacitor

This project is an independent implementation and does not use proprietary WhatsApp assets or branding.
